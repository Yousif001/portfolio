# Yousif - Portfolio

A clean, minimal personal portfolio site. Static HTML/CSS/JS, no build tools required.

## Live Site
Once GitHub Pages is turned on, visit:
[https://yousif001.github.io/portfolio/](https://yousif001.github.io/portfolio/)

## File Structure

```
portfolio/
├── index.html          # Main page (all sections)
├── cv.pdf              # Placeholder - replace with your real CV
├── css/
│   └── style.css       # All styles (mobile-first, responsive)
├── js/
│   └── main.js         # Nav toggle, scroll effects, reveal animations
└── README.md
```

## Run Locally

Any static file server will work. For example:

```bash
# Python 3
python3 -m http.server 8000
```
Then open `http://localhost:8000`.
